# 📸 SnapBooth

SnapBooth is a fun and aesthetic **web-based camera app** built with React that lets users capture photos with live filters, countdown effects, and a snap gallery, all directly from the browser.

Live Preview: https://snapbooth-mauve.vercel.app/
---

## ✨ Features

- 🎥 Live webcam preview
- 🎨 Real-time aesthetic filters (Glow, Sepia, Aesthetic, Black & White)
- ⏱️ Countdown timer before capture
- 😊 “Smile” prompt animation
- ⚡ Camera flash (blink) effect
- 🖼️ Snap gallery to preview captured photos
- 📥 Download all snaps
- 🗑️ Delete snaps with confirmation
- 🔔 Toast notifications using React Toastify


---

## 🛠️ Tech Stack

- **Frontend:** React + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Camera Access:** react-webcam
- **Notifications:** react-toastify
- **Version Control:** Git & GitHub

---

## 🚀 Getting Started

Follow these steps to run SnapBooth locally:

1️⃣ Clone the repository

git clone https://github.com/mmaryamhassan/SnapBooth.git

2️⃣ Navigate to the project folder

cd SnapBooth

3️⃣ Install dependencies

npm install

4️⃣ Start the development server

npm run dev

The app will run at:
http://localhost:5173
